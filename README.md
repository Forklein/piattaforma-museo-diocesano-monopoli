# Piattaforma digitale per il Museo Diocesano di Monopoli

Web app per la prenotazione di visite guidate e laboratori, la raccolta dei feedback dei visitatori, la consultazione del catalogo delle opere e il monitoraggio delle attività del museo.

Project work per la laurea triennale in Informatica per le Aziende Digitali (L-31), Università Telematica Pegaso, traccia n. 22.

**Titolo dell'elaborato:** Progettazione di una piattaforma informatica per il Museo Diocesano di Monopoli: architettura a livelli, gestione concorrente delle prenotazioni e analisi dei dati sui visitatori.

**Informazioni**: Trattasi di un sistema non ufficiale del Museo Diocesano di Monopoli, ma bensì di un prototipo didattico. Il nome del museo, le sale e le opere citate sono reali mentre attività, prenotazioni, visitatori e feedback sono dati simulati.

## Struttura del progetto

| Cartella | Contenuto |
|---|---|
| `backend/` | API REST in Python (FastAPI) e database relazionale (SQLite in locale, PostgreSQL in produzione) |
| `frontend/` | Interfaccia web in React con MUI |
| `docs/` | Diagrammi UML, schema del database e documentazione |
